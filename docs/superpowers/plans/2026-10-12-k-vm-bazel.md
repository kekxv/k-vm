# k-vm Bazel Implementation Plan

**Goal:** 将 TinyEMU 2019-12-21 整理为 k-vm，以模块化 Bazel 构建保留用户态网络、TAP 和 HTTP 存储。

**Architecture:** 公共头文件集中在 src/include，实现按 core、devices、arch、storage 分包；内置 SLIRP 作为 third_party 独立目标。主程序与辅助工具分离，统一编译宏，避免不同 XLEN 和网络宏产生 ABI 差异。

**Tech Stack:** C、Bazel 7.4.1、系统 libcurl/OpenSSL，SDL 1.2 可选。

## Constraints

- Linux 原生构建；默认 RV32/RV64/RV128、x86、SLIRP、HTTP 网络存储。
- 保留上游版权、许可证和原始发行压缩包。
- SDL 默认为关闭，通过 --config=sdl 启用。
- 不自动提交；当前工作区没有 Git 仓库，直接在工作区实施。
